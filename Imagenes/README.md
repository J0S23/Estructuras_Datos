# Imágenes esperadas

El juego ya intenta cargar estas rutas automáticamente (ver `assets.py`). Si el
archivo no existe todavía, la pantalla sigue funcionando con colores sólidos
de relleno — así que pueden ir agregando imágenes una por una sin romper nada
para nadie más del equipo.

Guarden los archivos exactamente con estos nombres y carpetas:

| Archivo | Descripción |
| --- | --- |
| `Imagenes/Personajes/ciudadano_idle.png` | Personaje jugable Ciudadano |
| `Imagenes/Personajes/periodista_idle.png` | Personaje jugable Periodista |
| `Imagenes/Personajes/influencer_idle.png` | Personaje jugable Influencer |
| `Imagenes/Fondos/fondo_ciudad.png` | Fondo de la pantalla Ciudad (960x600 o similar, se escala) |
| `Imagenes/Fondos/fondo_menu.png` | Fondo del menú principal (960x600) |
| `Imagenes/UI/icono_confianza.png` | Icono junto al indicador "Confianza ciudadana" (32x32 recomendado) |
| `Imagenes/UI/icono_verificacion.png` | Icono junto a "Información verificada" (32x32) |
| `Imagenes/UI/icono_desinformacion.png` | Icono junto a "Desinformación" (32x32) |
| `Imagenes/UI/icono_convivencia.png` | Icono junto a "Convivencia" (32x32) |

Formato PNG con fondo transparente cuando aplique (iconos y personajes).
Ver también `ASSETS_PENDIENTES.md` en la raíz del proyecto.
